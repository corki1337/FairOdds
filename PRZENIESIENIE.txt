## Zrób ZIP / skopiuj TERAZ

```
D:\blockchain\          ← cały folder najlepiej
```

Minimum krytyczne (bez tego zmienią się Program ID):

```
target\deploy\aichain-keypair.json
target\deploy\yield_park-keypair.json
```

Możesz pominąć: `node_modules`, `app\node_modules`, `app\.next`, większość `target\` (oprócz `deploy\*keypair*`).

## Na nowym PC

1. Wypakuj projekt
2. Zainstaluj Rust + Solana + Anchor **0.30.1** + Node 18+
3. `anchor build` → `anchor test` → deploy → `scripts/setup-devnet.ts` → `app` npm run dev

Szczegóły krok po kroku w **docs/HANDOFF.md**.
