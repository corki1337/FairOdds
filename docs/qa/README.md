# UI verification evidence

Generated by `tests/browser/smoke.mjs` against the local **production build**, using actual devnet reads. `browser-checks.json` records assertions, selected market and timestamp. Screenshots show the match board, a real resolved match on desktop/mobile, and the currently empty season list. `ui-walkthrough.webm` records those read-only screens; no transaction or upgrade was signed.

The final season-table assertion uses an isolated synthetic response after the recording is stopped, to verify the multi-participant layout before a live season is created. It is not presented as live-chain evidence. On-chain seasonal lifecycle/security are verified by solana-program-test using compiled SBF programs.

Reproduce: install dependencies, `npx playwright install chromium`, build/start the app, then `FAIRODDS_URL=http://localhost:3000 npm run test:browser`. It needs a reachable devnet RPC and at least one resolved market. Screenshots and recording may change with live state. This is QA evidence; the submission wallet demo still follows `../DEMO_CHECKLIST.md` after owner deployment.
